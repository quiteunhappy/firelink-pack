# Firelink

Souls-like, silly-horror modded Minecraft. Minecraft 1.20.1 + Forge, ~75 mods: Epic Fight combat, bonfires and Estus, Soulslike Weaponry, Cataclysm and friends for bosses, and a lot of things that go bump in the night.

## Install

1. Install [Prism Launcher](https://prismlauncher.org) and sign in with your Microsoft account.
2. **Add Instance → Import**, and paste this link:

   ```
   https://github.com/quiteunhappy/firelink-pack/releases/latest/download/firelink.mrpack
   ```

3. Edit the instance → **Settings → Java** → tick Memory and set the maximum to **8192 MB**.
4. Launch, then join the server address you were given.

## Updating

When the pack changes, import the same link again (it always points at the newest version). Check [Releases](https://github.com/quiteunhappy/firelink-pack/releases) for what changed.
