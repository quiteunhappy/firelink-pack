# Firelink

Souls-like, silly-horror modded Minecraft. Minecraft 1.20.1 + Forge, ~100 mods: Epic Fight combat, bonfires and Estus, Soulslike Weaponry, Cataclysm and friends for bosses, Goety necromancy, and a lot of things that go bump in the night.

## Install (Prism Launcher, auto-updating)

1. Install [Prism Launcher](https://prismlauncher.org) and sign in with your Microsoft account.
2. **Add Instance → Import**, and paste:

   ```
   https://github.com/quiteunhappy/firelink-pack/releases/latest/download/Firelink-Prism.zip
   ```

3. Launch it. The first launch downloads the mods (a small window shows progress), then the game starts.
4. Join the server address you were given.

That's it, forever: every time you press Play, the instance quietly syncs to the latest Firelink before the game starts. Your settings, keybinds, servers and resource packs are never touched. **Don't use Prism's own mod-update buttons on this instance**; the pack decides the versions.

Memory is preset to 8 GB (Edit → Settings → Java to change it).

### Coming from an older Firelink instance?

Before the first launch, copy `options.txt` (and `servers.dat`) from the old instance's `minecraft` folder into the new one's (right-click the instance → Folder) to keep your settings. Then delete the old instance.

## Other launchers

The Modrinth App (or anything that reads `.mrpack`) can import
`https://github.com/quiteunhappy/firelink-pack/releases/latest/download/firelink.mrpack`,
but it won't auto-update: re-import for each release.
